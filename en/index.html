Case 05Personal project2026

Quadro — a dashboard over Italy, on ISTAT data

Problem

A dashboard fed pre-computed totals can only answer the questions whoever prepared the data had anticipated. The first different question needs a change, a release and a week.

Approach

The browser receives the municipal detail — 7,896 rows — and aggregates on the fly. Changing level, indicator or filter is not a request to a server: it is a loop over an array.

The map weighs 99 KB because it is TopoJSON: quantised coordinates, points stored as deltas, and borders shared between neighbouring regions rather than duplicated. The same drawing as GeoJSON weighs 2,700.

Result

Fifty-one checks that reconcile the totals by every route and test them against facts that do not come from the data. On the first run Italy’s population came out at 118 million: the ISTAT file carries a total row per municipality, and summing it with the detail counts everything twice.

Case 06Personal project2026

Soglia — a WCAG contrast checker

Problem

A contrast ratio is a single number, and on its own it decides nothing: the same pair of colours passes at 24 px and fails at 16. The tools you find show the number with two fixed ticks beside it, and the real question goes unanswered — from what size up is this colour fine?

Approach

The threshold moves with size and weight, because that is how the standard is written. Transparency is composited before it is measured: rgba(0,0,0,.5) on white is #808080 and scores 3.95:1, not 21:1 — a tool that ignores alpha returns a number that exists on no screen.

And when it fails, it says which colour to use instead. The fix moves in lightness only, inside OKLCh, so the hue stays put and a corrected red stays red rather than turning pink. Sometimes, though, the right answer is that the background is wrong: on a mid grey no text colour whatsoever reaches 7:1, and saying so is worth more than offering a colour that does not solve it.

The real work is not one pair but a whole theme, where the pairs are n×n: paste the custom properties of a stylesheet and they all come out at once.

Result

A hundred and eighty-one checks, eight of them against numbers published by other people that I did not compute anywhere myself. The expectations are recomputed by a second implementation written in Python from the specification, not by the engine they are meant to test. And the page’s own theme passes its own tool against AAA, not AA: the check re-reads the stylesheet from disk, so a colour changed without looking at the contrast makes it fail.

Measuring the rendered page, rather than the declared colours alone, it found a defect of its own: on the matrix diagonal a grey dash at 12 px sat at 4.05:1. It was decoration disguised as text, and it is now a hatch.

One. When I take a job I am fully in it, with no queue and no splitting myself between clients competing for the same hours.

04What happens after delivery?

Delivery includes a support period. It is deliberately short — roughly a month — because its job is to cover the things that only surface once the software is genuinely in use: a fix, a detail to adjust, a question from someone using it every day.

If you want to continue after that, it extends. But I would rather it were your choice once you have seen how it goes, than a signature collected beforehand.

05Do you work remotely?

Yes, anywhere. I work fully remotely with no geographic limits: what it takes is a video call now and then and a written channel where you can reach me.

I work in English and Italian.

06Who owns the code you write?

The project code is yours. What I write for you — your process logic, your data model, your interfaces — is handed over with full repository access and stays yours. If you ever want to change supplier or bring the work in house, you do not need my permission.

There is one exception, and it is only fair to state it up front: the generic libraries and components I carry from one project to the next stay mine, and you get an unlimited, perpetual licence to use them within your project. That is not there to lock you in — it is what lets me avoid starting from zero every time, which is what makes the work cost you less.

The only thing I keep is the right to write the project up in my portfolio. If you would rather I did not, just say so.

07Can you take over a project someone else started?

It depends, and it needs looking at before anyone promises anything. Send me the code and tell me where things stopped: I will assess how much is salvageable, what is worth rewriting, and whether it makes more sense to continue or restart.

You get that assessment either way, even if we then decide not to work together. A clear answer beats a quote for something I have not seen.
